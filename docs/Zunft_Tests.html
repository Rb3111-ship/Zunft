How this plan works

Why these testsThe software tests already pass (500 app tests, 39 server-logic tests, 103 database tests). They cannot try a microphone, a camera, a fingerprint, a notification after a reboot, the battery, or the feel of the screens. This plan covers exactly that, plus the whole path from voice to invoice with realistic data.

What you need

  • An Android phone (two phones are best for the team parts), the newest zunft.apk from D:\Zunft_APK installed on each. Uninstall the old app first.
  • A computer with the Supabase dashboard open (for Part 0 and one SQL command in Test B).
  • A real paper receipt or two (a Baumarkt receipt is ideal), a PDF invoice on the phone, and a free e-invoice viewer or the FNFE-MPE web check for N27.
  • A quiet room: read the sentences in a normal voice, as you would on site.
What has changed since the first version of this test The app now has four tabs for boss and office (Aufträge, Termine, Kunden, Belege) plus Betrieb. The job list has the tabs Offen and Erledigt: a billed job moves to Erledigt. For company customers the invoice dialog has an e-invoice switch that is already on; that is fine, just leave it as suggested (the customers C5, C10 and C16 are companies with complete addresses). Positions the AI estimated carry "Preis prüfen" and must be confirmed with the tick box before "Fertigstellen". The "remember which tests you ran" rule: write the date next to each tick.
What to send meFor every tick list: "all ticked", or which line failed, with a screenshot or the exact message. For wrong figures: the rec number and what the app showed. For anything odd: a screenshot, even if you are not sure it is wrong.

Part 0 - Before you start: a clean slate

You wanted to delete your old test account. The app itself cannot delete an owner's account, because invoices must be kept by law. For the test project you wipe everything from the database instead:

1
In Supabase open SQL Editor → New query, paste the two lines below and press Run:
truncate table businesses cascade;
delete from auth.users;
This removes all test businesses, customers, jobs, notes, invoices and accounts. Only do it while the project holds nothing but test data. I could not try these two lines from here, so if Supabase shows an error, send me the exact text.
2
Optional: Storage → buckets captures and documents → select all files → delete. Leftover files do no harm, they only take space.
3
Recommended for testing: Authentication → Sign In / Providers → Email → switch Confirm email off. Then a new account works at once, without the e-mail link (that link currently leads to an error page; see the To-Do document, item 5.1). Switch it on again before real customers use the app.
4
On the phone: uninstall the Zunft app and install the newest zunft.apk from D:\Zunft_APK (this removes the old local data).

  1. Take a screenshot (power + volume down) of the screen and, if there is one, the message.
